# v0.1.5 real Blender test plan

CI can validate syntax, TypeScript, policy limits, checkpoint-path logic, and the cooperative execution-budget helper without Blender. Before declaring v0.1.5 stable, run the real Blender 5.2.1 smoke and one short live MCP session.

## Headless smoke

```powershell
& "E:\blan\blender.exe" -b --python .\scripts\blender-smoke.py
```

Expected final line:

```text
1782-92 blender smoke: PASS
```

The smoke now covers the generated-function shared scope, `M` helper path, forced checkpoint, transform/no-op regression checks, targeted inspect, quality, and render.

## Live MCP checks

After restarting Blender and the MCP client on v0.1.5:

```text
inspect({q:"summary"})
inspect({q:"collections"})
render({ref:"r5"})
```

Then make one small helper-backed mutation with `checkpoint:true`. Confirm the reply is fast, contains a revision/checkpoint, and the bridge remains responsive to another `inspect(summary)`.

For a large scene, confirm global `objects`, `quality`, and `oN:rings` are compact rather than dumping the entire scene/profile.

## Failure behavior

Do not intentionally hard-crash the working Speaky file. If testing the execution deadline, use a disposable blend and a pure-Python loop. A deadline error should end in `apply_budget_exceeded:split_batch` and the bridge should still answer `inspect(summary)` afterward.
